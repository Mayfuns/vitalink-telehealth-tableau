# Documentation

This folder summarises the business interpretation of the VitalLink analysis.

The project was framed around three operational problems:

1. **Alert overload** — Critical and non-critical alerts were competing within the same operational workflow.
2. **SLA blind spots** — average response time alone did not show how many individual high-priority alerts missed the target.
3. **Device-status uncertainty** — stakeholders needed evidence on whether model, battery or connectivity patterns were driving excessive Warning alerts.
